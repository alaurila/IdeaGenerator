    About the generator
    
      
    Game Idea Generator is a free browser tool for developers, game jam participants,
        solo creators and small teams looking for a starting point for their next game.
        Combine genres, goals, mechanics, settings and twists across 19 customizable fields.
    
      
    Generate idea creates a fresh example with 2–3 locked fields and 2–3 excluded fields to
        demonstrate the controls. All cards stay visible. Use Roll All to change the unlocked,
        included values, or select values directly from the lists. Multi-value fields support
        1–4 choices, including in Game jam mode.
    
      
    Open AI Prompt to copy a starting prompt for further brainstorming in an AI assistant.
        The generator combines the available options; it does not call an AI service itself.
        Use Copy idea for readable text, Copy link to restore your exact selections, or Download
        image for a PNG card with a small link back to the generator.
    
      
    The interface and idea lists support English, Finnish, Spanish, Portuguese and French;
        English is the default. Interactive generation requires JavaScript, while these instructions
        and the source catalogs can be read without it.
    
      
    Generate a fresh game idea.
    
    
    

    
    
      
    Game jam mode
    
      
    Use Game jam mode in the top bar to shape ideas around a concrete project: choose 24, 48
        or 72 hours, or one week; work solo, with 2–3 people, or with 4+ people; and select beginner,
        some experience or experienced. These settings change the suggested option pools and the AI prompt.
    
      
    Choose from 300 game jam themes in each supported language, roll a new theme, or enter
        the theme supplied by your jam. Lock a theme to keep it while rerolling the other fields.
        A theme gives the whole game a direction, while the twist adds a surprising detail.
        The prompt asks how the theme affects what the player actually does.
    
      
    Curated scope profiles favor smaller projects for shorter jams and less experienced teams.
        Your chosen value counts remain available. Locked choices are retained, and a card warning
        marks choices outside the suggested scope. The prompt helps define a smallest playable
        version and optional stretch goals; the suggestions do not guarantee a completion time.

    Instructions for bots
    
      
    Generate a fresh combination when asked for a new idea. Use a fixed seed only to replay
        an existing idea; do not present the fixed documentation example below as a new generation.
        English is the default language. Use another supported language when requested.
    
      
    With browser automation
    
      
      
        
    1. Open ?lang=en&fresh=1 in a JavaScript-capable browser.
          Navigate to that address again for each new idea, rather than reloading the resulting seed URL.
      2. 
        
    2. Wait until #idea-output contains a JSON object with a non-null seed
          and categories, then parse its text content. This is the currently displayed idea.
      3. 
        
    3. For a scoped jam idea, add jam=1&hours=48&team=solo&experience=beginner.
          Read the selected theme and constraints from the result's jam object.
      4. 
      
    
      
    Without browser automation
    
      
    Fetch the appropriate catalog and generate a combination locally. Catalogs contain
        options, not pre-generated ideas. A plain HTTP request to this static page does not run
        the generator. The public ideaEngine.js module exports
        generateIdea({ catalog, language, seed }); use a fresh random seed for each new idea.
    
      
    From a local checkout, this command prints a fresh JSON idea using the default English catalog:
    
      
    npm run --silent generate -- --lang en
    
      
    For a scored combination, add --smart. It evaluates 500 candidates locally,
        randomly picks from the top ten qualifying combinations, and returns scores,
        explanations (including localized text) and smart search details in the JSON.
    
      
    npm run --silent generate -- --smart --lang en
    
      
    Combine --smart with language, jam or catalog options. To replay a smart result,
        keep --smart and pass its --seed with the same options and versions;
        an ordinary browser seed URL runs ordinary generation. Use current catalogs containing
        scoring metadata. No pre-generated idea or LLM/API call is used for smart search.
        JavaScript bots can also import generateSmartIdea().
    
      
    Add --jam --hours 48 --team solo --experience beginner for a jam idea,
        or --catalog-url followed by a catalog URL to use the served data.
        Full response fields, theme options and examples are in the API and AI usage guide.

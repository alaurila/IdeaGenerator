API and AI usage guide

Interactive generator. To get a new game idea, generate a fresh combination from a catalog using a newly generated seed for each request. The fixed example on the home page illustrates the data format. Use a fixed seed only when someone explicitly asks to reproduce an existing idea.

English (en) is the default language. Choose another supported language when requested.

Generate a fresh idea from a terminal

In a local checkout, run the following command. It prints a new versioned idea as JSON to standard output each time, using a random UUID seed. It does not select a pre-generated idea.

npm run --silent generate -- --lang en

To read the currently published catalog instead of the local copy:

node scripts/generate-idea.js --lang en --catalog-url https://alaurila.github.io/IdeaGenerator/data/en/catalog.json

Only pass --seed my-idea-123 when replaying a specific idea.

Generate using browser automation

Open ?lang=en&fresh=1 in a JavaScript-capable browser. Every navigation to that address generates a fresh seed and overrides previously saved state, even if a seed parameter was also supplied. The address then changes to the reproducible seeded URL.

Wait until #idea-output contains a JSON object, then parse its text content. This is the actual currently displayed idea. The following Playwright example assumes an existing page:

await page.goto('https://alaurila.github.io/IdeaGenerator/?lang=en&fresh=1');
await page.waitForFunction(() => {
  const text = document.getElementById('idea-output')?.textContent;
  return text && JSON.parse(text)?.seed !== null && JSON.parse(text)?.categories;
});
const idea = JSON.parse(await page.locator('#idea-output').textContent());

After manual edits, the current-idea JSON uses seed: null and an empty array for excluded categories. JSON is populated at runtime; fetching the original HTML without running JavaScript returns no generated idea.

Catalogs for bots without browser automation

Fetch the appropriate catalog, then generate a combination locally. These files contain all available options, not completed ideas. A plain HTTP request to this static site does not execute the generator.

  • English / en (default)
  • Suomi / fi
  • Espa?ol / es
  • Portugu?s / pt
  • Fran?ais / fr

Use the pure generation module described below, or sample options yourself if you cannot run JavaScript. For the default category counts, choose two distinct options for genres, core_mechanics, moods, npc_structures and generative_elements, and one for every other category. To reproduce the module's results in another language, port its seeded algorithm and sort each category by ID before sampling. Never report the fixed documentation example as a newly generated idea.

Versioned response format

Every idea contains the following fields. The categories below are an abbreviated illustration; generated ideas contain every category listed in the catalog.

{
  "schemaVersion": 2,
  "generatorVersion": 1,
  "catalogVersion": "<SHA-256 of the normalized catalog categories>",
  "language": "en",
  "seed": "my-idea-123",
  "categories": {
    "player_roles": [{ "id": "player_roles-0001", "text": "<translated label>" }]
  }
}
  • schemaVersion: JSON contract version. Version 2 uses option objects instead of strings.
  • generatorVersion: generation algorithm version, currently 1.
  • catalogVersion: content hash of categories and their translated options. Each language has its own hash.
  • language: one of en, fi, es, pt, fr.
  • seed: a string, including the empty string, used for deterministic generation.
  • categories: stable category keys mapping to arrays of options. Every option has a permanent id and a localized text.

A catalog contains schemaVersion, catalogVersion, language, labels (category titles) and categories (all options).

Match options across languages by id. IDs are stored in the source files and remain unchanged when labels are corrected or lists reordered. Never treat array positions or translated labels as identifiers.

Generate a fresh idea without a browser

Import the public ES module and fetch a catalog. The function performs no network or storage operations.

import { generateIdea } from './js/ideaEngine.js';

const response = await fetch(
  'https://alaurila.github.io/IdeaGenerator/data/en/catalog.json'
);
if (!response.ok) throw new Error(`Catalog: HTTP ${response.status}`);
const catalog = await response.json();
const idea = generateIdea({
  catalog,
  language: 'en',
  seed: crypto.randomUUID() // A fresh seed for every new idea.
});

The import above is relative to a local copy of the project. Browser modules can also import js/ideaEngine.js from this site. Unsupported schema versions, mismatched catalog languages and invalid categories throw an error.

Open or share the same idea

Open the English example using ?lang=en&seed=my-idea-123 on the home page. The language and seed override saved browser state. First visits without a saved idea demonstrate the controls with two locks and two or three excluded fields; these demonstrations have no replay seed. Use fresh=1 for a complete seeded idea without demonstration locks or exclusions. Editing values or excluding categories removes the seed.

The same seed, language, catalog content and generator version produce the same result. Reordering source options does not affect it. Changes to available options or the generation algorithm may change results. Seeded URLs use the currently published catalog; they do not archive old catalog versions. Store the complete idea JSON if exact long-term preservation is required.

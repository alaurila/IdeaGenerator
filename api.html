API and AI usage guide

Interactive generator. To get a new game idea, generate a fresh combination from a catalog using a newly generated seed for each request. The fixed example on the home page illustrates the data format. Use a fixed seed only when someone explicitly asks to reproduce an existing idea.

English (en) is the default language. Choose another supported language when requested.

Generate a fresh idea from a terminal

In a local checkout, run the following command. It prints a new versioned idea as JSON to standard output each time, using a random UUID seed. It does not select a pre-generated idea.

npm run --silent generate -- --lang en

To read the currently published catalog instead of the local copy:

node scripts/generate-idea.js --lang en --catalog-url https://alaurila.github.io/IdeaGenerator/data/en/catalog.json

Only pass --seed my-idea-123 when replaying a specific idea.

Smart generation and compatibility scores

Add --smart to generate a fresh idea and evaluate 500 candidate combinations. The search chooses randomly from the top ten distinct combinations scoring at least as highly as the initial idea. If none qualify, it keeps the initial idea. Scoring uses genre, setting, core mechanics, mood and twist only. No LLM, API key or external scoring service is used.

npm run --silent generate -- --smart
npm run --silent generate -- --smart --lang fi
npm run --silent generate -- --smart --jam --hours 48 --team solo --experience beginner
node scripts/generate-idea.js --smart --catalog-url https://alaurila.github.io/IdeaGenerator/data/en/catalog.json

All existing language, jam, theme and catalog options work with --smart. English is the default, and a fresh UUID seed is used unless you explicitly request a replay. These commands generate combinations from the catalog, not saved examples.

The versioned idea JSON additionally contains:

  • scores: numeric synergy, tension, novelty, conflict and total, each between 0 and 100. Contrasts increase tension; only explicit conflicts incur a penalty. Commonness is an initial estimate, not measured popularity.
  • explanations: one to three objects with a template key, evidence params and readable text translated into the selected language. Metadata trait identifiers in params stay English.
  • smart: version (currently 1), candidateCount (500), topCount (10), evaluated (candidate attempts), changed and reason (selected or noImprovement).

Replay with both --smart and the returned --seed, keeping the language, catalog, jam/theme options and smart algorithm/scoring version unchanged:

npm run --silent generate -- --smart --lang fi --seed my-smart-idea

An ordinary ?seed= browser link runs ordinary generation, not smart search. Archive the full JSON for exact long-term preservation. The UI's Copy link action shares the actual selections of ideas created in the browser, including Smart Roll results.

A current catalog with complete scoring metadata is required. If --smart reports missing scoring metadata, run npm run build for local data or update the served catalog. Without --smart, the command retains ordinary generation and its existing JSON fields.

JavaScript bots can use the browser-independent module with the same options as generateIdea(), including optional jam and counts:

import { generateSmartIdea } from './js/smartGeneration.js';

const idea = await generateSmartIdea({
  catalog,
  language: 'en',
  seed: crypto.randomUUID()
});
const { scores, explanations, smart } = idea;

The module returns explanation keys and parameters; the CLI also adds localized text. The module does not fetch catalogs, access the DOM or read storage.

Generate using browser automation

Open ?lang=en&fresh=1 in a JavaScript-capable browser. Every navigation to that address generates a fresh seed and overrides previously saved state, even if a seed parameter was also supplied. The address then changes to the reproducible seeded URL.

Wait until #idea-output contains a JSON object, then parse its text content. This is the actual currently displayed idea. The following Playwright example assumes an existing page:

await page.goto('https://alaurila.github.io/IdeaGenerator/?lang=en&fresh=1');
await page.waitForFunction(() => {
  const text = document.getElementById('idea-output')?.textContent;
  return text && JSON.parse(text)?.seed !== null && JSON.parse(text)?.categories;
});
const idea = JSON.parse(await page.locator('#idea-output').textContent());

After manual edits, the current-idea JSON uses seed: null and an empty array for excluded categories. JSON is populated at runtime; fetching the original HTML without running JavaScript returns no generated idea.

For interactive smart search, click #smart-roll and wait until it is enabled again. The page shows the scores and explanations; #idea-output contains the selected idea. Use the CLI's --smart response when you need scores and explanation text together as JSON.

Catalogs for bots without browser automation

Fetch the appropriate catalog, then generate a combination locally. These files contain all available options, not completed ideas. A plain HTTP request to this static site does not execute the generator.

  • English / en (default)
  • Suomi / fi
  • Español / es
  • Português / pt
  • Français / fr

Use the pure generation module described below, or sample options yourself if you cannot run JavaScript. For the default category counts, choose two distinct options for genres, core_mechanics, moods, npc_structures and generative_elements, and one for every other category. To reproduce the module's results in another language, port its seeded algorithm and sort each category by ID before sampling. Never report the fixed documentation example as a newly generated idea.

Share the current idea

The top bar offers Copy idea (readable text), Copy link (an exact snapshot of the current selections) and Download image (PNG). Text and image exports contain every included field, any active jam settings and theme, and a small link to the generator. Excluded fields are omitted.

Snapshot links use a versioned #idea= URL fragment containing permanent option IDs, counts, lock/exclusion flags and jam settings. They restore edited ideas and demonstrations independently of saved browser state. JavaScript restores the fragment locally; the server does not receive it. Removed options or malformed snapshots display an error. Existing seed links remain supported.

Game jam generation

Enable Game jam mode in the top bar, or open a fresh 48-hour solo beginner jam idea. All 19 cards remain visible. The constraints panel follows AI Prompt.

URL parameters: jam=1, hours=24|48|72|168, team=solo|small|large, experience=beginner|intermediate|experienced, optional themeId or custom theme, and themeLock=1. A fresh seed gives a fresh unlocked theme; a locked theme stays while the other fields roll. Custom theme text is limited to 200 characters.

Each catalog includes jam.themes: 300 localized themes with shared permanent IDs. They are also available in data/en/jam_themes.json (replace en with another supported language). Profiled category options have optional jam.level and jam.tags. jam.constrainedCategories lists categories whose random pool is restricted, and jam.policyVersion identifies the policy.

const idea = generateIdea({
  catalog,
  language: 'en',
  seed: crypto.randomUUID(),
  jam: {
    enabled: true, hours: 48, team: 'solo', experience: 'beginner',
    themeId: 'jam_theme-0004', themeLocked: true
  }
});

For a custom locked theme, use themeText instead of themeId. Jam results add a jam object containing settings and the selected theme: { id, text }. A custom theme has id: null. Jam generation uses the normal category counts; optionally pass counts: { genres: 4, core_mechanics: 3 } to the pure generator. The usual 1–4 value controls remain available regardless of jam constraints. Filtered pools expand when necessary to honor the chosen counts. Generation otherwise draws using curated complexity tiers constrained by time, team size and experience. Scope guidance is approximate.

npm run --silent generate -- --jam --hours 48 --team solo --experience beginner
node scripts/generate-idea.js --jam --theme "Echo" --seed my-jam-idea

Generate idea creates a demonstration with 2–3 locked and 2–3 excluded fields. Roll All preserves locks and exclusions; retained out-of-scope selections receive a card warning. Use fresh=1 or a seed URL for full reproducible results.

Versioned response format

Every idea contains the following fields. The categories below are an abbreviated illustration; generated ideas contain every category listed in the catalog.

{
  "schemaVersion": 2,
  "generatorVersion": 1,
  "catalogVersion": "<SHA-256 of the normalized catalog categories>",
  "language": "en",
  "seed": "my-idea-123",
  "categories": {
    "player_roles": [{ "id": "player_roles-0001", "text": "<translated label>" }]
  }
}
  • schemaVersion: JSON contract version. Version 2 uses option objects instead of strings.
  • generatorVersion: generation algorithm version, currently 1.
  • catalogVersion: content hash of categories and their translated options. Each language has its own hash.
  • language: one of en, fi, es, pt, fr.
  • seed: a string, including the empty string, used for deterministic generation.
  • categories: stable category keys mapping to arrays of options. Every option has a permanent id and a localized text.

A catalog contains schemaVersion, catalogVersion, language, labels (category titles) and categories (all options), plus the jam catalog described above.

Match options across languages by id. IDs are stored in the source files and remain unchanged when labels are corrected or lists reordered. Never treat array positions or translated labels as identifiers.

Generate a fresh idea without a browser

Import the public ES module and fetch a catalog. The function performs no network or storage operations.

import { generateIdea } from './js/ideaEngine.js';

const response = await fetch(
  'https://alaurila.github.io/IdeaGenerator/data/en/catalog.json'
);
if (!response.ok) throw new Error(`Catalog: HTTP ${response.status}`);
const catalog = await response.json();
const idea = generateIdea({
  catalog,
  language: 'en',
  seed: crypto.randomUUID() // A fresh seed for every new idea.
});

The import above is relative to a local copy of the project. Browser modules can also import js/ideaEngine.js from this site. Unsupported schema versions, mismatched catalog languages and invalid categories throw an error.

Open or share the same idea

Open the English example using ?lang=en&seed=my-idea-123 on the home page. The language and seed override saved browser state. First visits without a saved idea and Generate idea demonstrate the controls with two or three locks and two or three excluded fields; these demonstrations have no replay seed. Use fresh=1 for a complete seeded idea without demonstration locks or exclusions. Editing values or excluding categories removes the seed.

The same seed, language, catalog content and generator version produce the same result. Reordering source options does not affect it. Changes to available options or the generation algorithm may change results. Seeded URLs use the currently published catalog; they do not archive old catalog versions. Store the complete idea JSON if exact long-term preservation is required.
